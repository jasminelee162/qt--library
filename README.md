# Qt--SSD4--library

版本信息：qt5.14.2 MSVC2015_64

## 项目简介

本项目是一个基于 Qt5 开发的图书馆管理系统，旨在为管理员和普通用户提供便捷的平台，实现图书借阅、管理和通知发布等功能。系统区分用户和管理员两种角色：

- 用户可注册、登录、借还图书、查看个人信息及借阅记录，接收管理员通知，查阅帮助信息等。
- 管理员可管理图书信息及用户、导出借阅记录、发布系统通知、查看帮助信息等。

## 系统功能

### 用户功能

1. **注册与登录**
   - 用户可通过注册界面填写用户名、密码及个人信息并注册新账号。系统会验证用户名唯一性。
   - 登录时输入用户名与密码，如信息错误会有提示。

2. **密码找回**
   - 在登录界面可通过邮箱或用户名找回密码，系统将重置链接发送至用户邮箱。

3. **图书借阅与归还**
   - 用户可在主界面选择图书进行借阅，设置借阅期限，系统自动更新数据库。
   - 借阅时系统显示可借图书，并自动设定应归还日期。
   - 用户可还书，系统更新借阅状态。

4. **个人信息与借阅记录**
   - 支持用户查看和导出个人借还书记录。
   - 可修改部分个人信息。

5. **通知与帮助**
   - 用户可接收管理员发布的系统通知。
   - 可查阅帮助文档，了解系统操作说明。

### 管理员功能

1. **管理员登录与注册**
   - 管理员同样需注册、登录。

2. **图书信息管理**
   - 支持图书的添加、删除、修改（包括书本ID、出版社、出版年份、馆藏数量、封面、简介等）。

3. **用户信息管理**
   - 查看所有用户信息，管理用户账号。

4. **借阅记录管理**
   - 管理员可导出所有用户的借阅记录（CSV格式）。

5. **通知发布**
   - 支持向所有用户发布系统通知。

6. **帮助信息**
   - 管理员可查阅帮助文档，获得操作指引。

## 安装与运行

1. **环境准备**
   - Qt 5.14.2 (建议 MSVC2015_64)
   - 支持 C++11 及以上
   - 数据库依赖：SQLite

2. **获取项目**
   ```bash
   git clone https://github.com/jasminelee162/qt--library.git
   cd qt--library
   ```

3. **编译说明**
   - 使用 Qt Creator 打开 `.pro` 项目文件。
   - 配置好编译器和环境，直接构建并运行。

4. **数据库初始化**
   - 首次运行会自动创建所需数据库表（如 users、books、borrow_info、notifications）。
   - 可按需导入测试数据。

## 使用说明

- 初次运行建议先注册一个管理员账号，添加部分图书后再注册普通用户账号进行测试。
- 图书借还、信息查看等均可在主界面完成。
- 管理员可通过管理界面管理图书和用户、导出记录、发布通知。
- 帮助文档可在“帮助”界面随时查阅。
